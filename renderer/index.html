DeepSeek (深度求索) DEEPSEEK_API_KEY
📖 如何获取 DeepSeek API 密钥？
  1. 访问 platform.deepseek.com 并登录（需注册账号）
  2. 注册后进入「API Keys」页面
  3. 点击「Create API Key」创建新密钥
  4. 复制密钥并粘贴到上方输入框中
  5. 首次充值可选择自定义充值 1 元体验，用量很少，普通开发能用很久
  6. * 本处支付费用为支付 DeepSeek 的 token 服务费用，并非支付给本工具开发者！
  7. * 后续使用，请进入官网查看 API 用量，充值费用使用完后本地将无法访问其 API！
